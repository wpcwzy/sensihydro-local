# 寄存器表（实测）

> 编码规则：温度类 `℃ = (raw - 3000) / 100`，写入时 `raw = 3000 + ℃ × 100`。
> 单次读最多 20 个寄存器。以下地址来自一台 6 内机 + 1 外机的实测设备，
> **不同机型/接法可能不同**，请先只读确认。

## 1. 内机状态块（20 个寄存器，`0x00C8 + 20 × (槽位-1)`）

| 偏移 | 含义 | 换算 |
|---|---|---|
| +0 | 内机控制板软件版本 | 原值 |
| +1 | 显示面板软件版本 | 原值 |
| +2 ~ +4 | 内机识别码 高/中/低 | 原值 |
| **+5** | **回风温度** | `(raw-3000)/100` ℃ |
| +6 | 浮球开关 | 0/1 |
| +7 | 地暖热阀继电器 | 0/1 |
| +8 | 排水泵继电器 | 0/1 |
| +9 | 二通阀方向 | 0/1 |
| +10 | 内机风机转速 | rpm |
| **+13** | **线控器环境温度（室温）** | `(raw-3000)/100` ℃ |
| +14 ~ +19 | 预留/其他 | — |

## 2. 内机控制块（4 个寄存器，`0x03E8 + 15 × (槽位-1)`）

| 偏移 | 含义 | 取值 |
|---|---|---|
| +0 | 开关 | `1` 开 / `0` 关 |
| +1 | 模式 | `模式号 << 8 \| 开关位` |
| +2 | 目标温度 | `3000 + ℃ × 100` |
| +3 | 风速 | `0x0100` 自动；`1`~`10` 手动档位 |

模式号：`0` 冷风、`1` 送风、`2` 热风、`3` 地暖、`4` 热+暖、`5` 除湿。

## 3. 主机模式（`0x05DC` 起）

| 寄存器 | 含义 | 取值 |
|---|---|---|
| `0x05DD` | 出水温度设定 | `45` = 常规/节能/静音；`50` = 强热 |
| `0x05DE` | 静音标志 | `1` 开 / `2` 关 |
| `0x05DF` | 规律未知（随模式变化，`5` 左右） | — |
| `0x05E0` | 节能标志 | `1` 开 / `2` 关 |

组合与云端 `deviceMode` 的对应：

| 静音 | 节能 | 强热 | 出水温度 | 模式 | `deviceMode` |
|---|---|---|---|---|---|
| 关 | 关 | 关 | 45℃ | 常规 | 0 |
| 关 | 开 | 关 | 45℃ | 节能 | 1 |
| 开 | 开 | 关 | 45℃ | 节能+静音 | 2 |
| 开 | 关 | 关 | 45℃ | 静音 | 3 |
| 关 | 关 | 开 | 50℃ | 强热 | 5 |
| 关 | 开 | 开 | 50℃ | 强热+节能 | 6 |
| 开 | 关 | 开 | 50℃ | 强热+静音 | 7 |
| 开 | 开 | 开 | 50℃ | 强热+节能+静音 | 8 |

写入要点：

1. 顺序：先 `0x05DE`、`0x05E0`，最后 `0x05DD`；
2. 每条写命令间隔约 2–5 秒，否则会被静默丢弃；
3. 写完回读校验，不一致就重试。

## 4. 外机诊断参数（`0x0064` ~ `0x007C`）

云端参数表 `val100..val124` 与寄存器一一对应：

| 寄存器 | 云端参数 | 含义 | 换算 |
|---|---|---|---|
| `0x0064` | val100 | 室外环境温度 Ta | `(raw-3000)/100` ℃ |
| `0x0065` | val101 | 室外盘管温度 Tp | 同上 |
| `0x0066` | val102 | 室外排气温度 Td | 同上 |
| `0x0067` | val103 | 室外回气温度 Ts | 同上 |
| `0x0068` | val104 | 制冷水温度 Tc | 同上 |
| `0x0069` | val105 | 用户侧出水温度 TO | 同上 |
| `0x006A` | val106 | 用户侧回水温度 TI | 同上 |
| `0x006B` | val107 | 用户侧盘管温度 TC1 | 同上 |
| `0x006C` | val108 | 制热出水温度 | 同上 |
| `0x006D` | val109 | AC 输入电压 | `raw/10` V |
| `0x006E` | val110 | AC 输入电流 | `raw/10` A |
| `0x006F` | val111 | 压缩机运行转速 | `raw` Hz |
| `0x0070` | val112 | 主路电子膨胀阀开度 | `raw` P |
| `0x0071` | val113 | 辅路电子膨胀阀开度 | `raw` P |
| `0x0072` | val114 | 蒸发器压力 | `raw/10` |
| `0x0073` | val115 | 冷凝器压力 | `raw/10` |
| … | … | 其余为运行状态/版本/故障位 | 见云端参数表 |

## 5. 内机参数（云端 `val200..val213`）

云端参数表里内机的 `val200..val210`、`val213` 与状态块一一对应
（版本、识别码、回风温度、浮球、地暖阀、排水泵、二通阀、风机转速、线控器室温）。
本地读取后覆盖云端缓存值，所以 HA 里的这些传感器是实时的。

## 6. 默认映射与校验（重要）

bridge 默认的「房间 → 槽位」映射不是猜的，而是用**每块内机板的唯一识别码**
（状态块 +2/+3/+4）与云端参数表里各房间的识别码逐一对上的：

| 房间 | 槽位 | 状态块 | 控制块 |
|---|---|---|---|
| 餐厅 | 1 | `0x00C8` | `0x03E8` |
| 三楼南 | 2 | `0x00DC` | `0x03F7` |
| 二楼南 | 4 | `0x0104` | `0x0415` |
| 三楼北 | 5 | `0x0118` | `0x0424` |
| 客厅 | 6 | `0x012C` | `0x0433` |
| 二楼北 | 7 | `0x0140` | `0x0442` |

装好后打开 `http://<bridge>:8090/api/mapping` 可以看到 bridge 实际使用的映射和每台机器的识别码；
对照云端参数表（或本仓库 `examples/units.zh-CN.json`）即可确认没有错位。
如果映射错了，表现就是"遥控器点 A 房间，B 房间的空调动了"。

自定义映射：把 `examples/units.example.json` 改成自己的房间名/槽位，用 `UNITS_FILE` 环境变量指向它。

## 7. 如何探测自己的设备

1. **确认 DTU 通信**：`curl http://<bridge>:8090/api/read?addr=0x00c8&count=20`，
   能读到数据说明通道 OK；
2. **找内机槽位**：从 `0x00C8` 起按 20 递增读，找到"回风温度/室温看起来合理"的块；
3. **核对控制块**：每个状态块的槽位对应 `0x03E8 + 15×(槽位-1)`；
4. **写入验证**：改一台机器的目标温度（±0.5℃），同时观察读回值、官方 App、机器反应；
5. **主机模式**：参考上面表格，逐个组合写三个寄存器并回读确认。

> ⚠️ 写寄存器会真实改变空调行为。建议先在没人使用的时段做，并确保能随时停容器回滚。

## 7. 调试接口

```bash
# 读任意寄存器
curl 'http://<bridge>:8090/api/read?addr=0x05dc&count=5'

# 写单个寄存器（十六进制字符串或数字均可）
curl -X POST -H 'Content-Type: application/json' \
     -d '{"addr":"0x0435","value":"0x13ba"}' \
     http://<bridge>:8090/api/write
```
